# Figma AI Prompt — Accelerate Landing Page, Hero A ("Guarantee Lead")

Copy everything below into Figma AI as one prompt.

---

Design the **Hero section** of a landing page for "Accelerate," a content-marketing/social-growth agency. This is variant **A — the Guarantee Lead**. It is the very first section on the page, so it also contains the top navigation bar. There is **no video** in this hero — use a single static placeholder image instead. Do not add any copy beyond what's listed below.

## Mood / Direction
Clean, confident, premium "quietly expensive" agency aesthetic — closer to an editorial site than a typical SaaS template. Generous whitespace, oversized punchy typography, one accent color used sparingly, small hand-crafted details (a highlighted word, an overlapping avatar stack) instead of gradients or 3D clichés.

## Color Palette
- Background: `#FFFFFF` (or `#FAFAFA`)
- Primary text: `#111111`
- Secondary/body text: `#5B5F66`
- Accent (brand blue): `#1A56DB`
- Accent tint (for tag/pill backgrounds): `#EAF1FF`
- Hairline / borders: `#E7E7E7`

## Typography
- Headline: large, bold, tight line-height display sans (think Neue Montreal / General Sans / Söhne — not default Inter or Poppins), ~64–84px desktop
- One phrase set in an italic serif (think GT Sectra / Times Now / Canela Italic) for a single editorial contrast moment — don't italicize everything, just one emphasis point
- Body/tagline: clean regular-weight sans, `#5B5F66`, ~18–20px
- Button label: medium/semibold sans, ~15–16px, slightly wide letter-spacing
- Any tag/eyebrow text: small uppercase bold, ~12–13px, wide letter-spacing

## Layout (top to bottom, single centered column, max-width ~880px)

**1. Top nav**
Minimal bar, ~72–88px tall. Logo/wordmark placeholder "Accelerate" on the left. 2–3 plain text links on the right (Work, Case Studies, Contact). No background box, optional hairline bottom border. Keep it quiet — it should not compete with the headline below.

**2. Headline**
Exact copy: `1,000,000 Views Guaranteed in 90 Days.`
Give ONE word or phrase a hand-drawn-feeling emphasis — either a soft blue marker-highlight behind it, or a thin blue outline box around it. Pick only one technique, don't stack effects. Two lines max on desktop, tight leading (~1.05).

**3. Sub-headline**
Exact copy: `Or Your Money Back.`
Smaller than the headline, set in the italic serif accent font described above (or bold black) — reads like a punchline, not a new paragraph.

**4. Tagline**
Exact copy: `The most measurable guarantee in content marketing.`
Regular weight, gray, single centered line.

**5. CTA button**
Exact copy: `Book a Call`
Solid accent-blue pill button, white text, fully rounded corners, generous padding (~14px vertical / 32px horizontal). Subtle hover (darken ~8%). No heavy drop shadow — a crisp flat button, maybe a 1px darker-blue border at most.

**6. Social proof row**
Exact copy: `Used by Robert Herjavec, Daniel Lubetzky, Jane Lu, and many others.`
Pair it with a small overlapping stack of 4 circular placeholder headshots (~32px, white 2px border, slight overlap) to the left of the line. Keep this understated — it's a quiet trust signal below the CTA, not a hero element. Use neutral placeholder headshots, not real photos of the named people.

**7. Hero visual (static image, no video)**
Place one static placeholder image below the text block — something like a vertical (4:5 or 9:16) shot suggesting a creator filming short-form video, or a phone-frame mockup of a Reels-style UI. Contain it in a clean rounded-corner card (20–28px radius), thin 1px hairline border, minimal or no shadow. Keep it modest in scale — the guarantee headline is the star of this hero, the image is a supporting visual, not a big autoplay block.

## Spacing
Generous vertical rhythm: ~120–160px padding under the nav, ~80–100px between each major block below. Single column, centered, no split two-column hero.

- The highlighted-word / outline-box emphasis technique and the overlapping avatar-stack: borrowed from the copy-style reference, re-colored in our blue instead of their yellow/red/pink
- The mixed italic-serif + bold-sans type pairing for one emphasis moment: borrowed from the testimonial-style reference
- All colors strictly follow the "for colors" reference screenshots: white background, black text, blue accent

## Explicitly avoid
- Purple/blue generic SaaS gradient-mesh backgrounds
- 3D glass orbs, blobs, or floating abstract shapes
- Stock rocket-ship / handshake icons
- Heavy soft drop shadows or glassmorphism cards
- Default Inter-everything / generic Tailwind-template look
- Perfect, sterile symmetry — allow one small imperfect detail (a slightly offset tag, an avatar breaking the grid) so it reads hand-built
- Any copy beyond the five lines given above (headline, sub-headline, tagline, CTA, social proof)
